途中でやめる場合だけ保存してください。「下書きを共有保存」はこの投稿の入力内容を保存します。商品名や価格表の保存とは別です。

STEP 2 / 3 — 価格と掲載を確認

掲載する商品を確認

商品カードの「投稿に含める」を外すと、その行は投稿に出ません。同じ商品は仕入れ値や入力順に関係なく1つにまとまり、S/A → AM → Bの順に掲載します。

押すとSUMdexのNotion価格と国内の表示価格をもう一度取得します。赤字は通常停止しますが、商品ごとに確認して掲載を許可できます。

STEP 3 / 3 — 確認して投稿

Discordへの投稿プレビュー

「投稿内容を確認」を押してください。

ボタンを押すと実際に投稿されます。画像未登録の商品は文章だけで表示します。投稿済みの内容は自動更新されません。

困ったときの使い方
  1. 商品名を検索し、出てきた候補を押して確定します。SUMdex価格と国内最高表示額が自動で表示されます。
  2. 税込の仕入れ値を入力し、S・A／AM／Bから状態を1つ選びます。割引額はその商品だけ変更することもできます。
  3. 「おすすめを自動選択」の理由を確認します。価格を取得できない場合は、表示されたボタンから商品名・型番の紐づけを確認します。
  4. 必要なら「この行を複製」や「商品をもう1行追加」で掲載候補を増やし、不要な行は「投稿に含める」を外します。
  5. 赤字の場合は赤字額を確認し、それでも掲載する商品のチェックを入れます。チェックしない赤字商品は投稿を止めます。
  6. 「投稿内容を確認」を押し、投稿先・金額・状態・画像を確認し、チェックを入れて「この内容でDiscordに投稿する」を押します。

PRODUCT MASTER

商品名の紐づけ・価格表

操作方法：取り込み・編集・販売価格の登録

ワンピースを使うには：「ワンピース商品をまとめて追加」を押す → 英語名・型番・価格を確認 →「商品表を共有保存」。Notionと国内価格を型番で照合し、一意に決まる商品だけ追加します。その後は投稿作成画面でポケモンと同じように選べます。国内価格は両方のサイトから取得します。

  1. CSVは国内商品名（ja）に英語名（en）または型番（code）を付ければ取り込めます。価格と価格表URLは後で入力できます。何も書き足していない行は取り込みません。
  2. 「CSVを取り込む」を選ぶと画面に追加されます。この時点では他のPCに保存されません。画面下の件数と商品を確認し、「商品表を共有保存」を押してください。
  3. 下の検索欄で商品を探し、ブラウザ上で名前・型番・別表記を編集、商品を追加・削除できます。変更後は再度「商品表を共有保存」を押してください。
  4. 販売する商品だけSUMdex価格と参照先を記入し、価格表を目視確認して「価格を確認済みにする」→「商品表を共有保存」を押します。名前だけ登録した商品は投稿文に使えません。

型番は任意です。型番がない商品は空欄のまま英語名を登録すると、商品名だけで投稿できます。型番の大小文字は検索・照合で区別しません。同じ型番でも別商品として登録できます。SUMdexに英語名が載っていない場合は、確認した他サイトの英語名を掲載名として登録してください。日本語名と英語名が文字どおり一致する必要はありません。

基準価格を確認：SUMdex価格表 ／ ONE PIECE価格表

投稿文の生成・投稿時にNotionの公開価格表を確認します。取得できない、または商品を一意に特定できない場合は投稿を止めます。Notion側の形式変更に備え、CSV取り込みも利用できます。

SUMdexの最新価格を照合

「Notion価格を今確認」で公開価格表を取得します。英語名・型番（大小文字を区別しません）から既存商品を探します。同じ型番の商品など判別できない行は下の一覧で選ぶか除外してください。読み込みだけでは保存されません。

CSVの列には「商品名」または「型番」と「価格」が必要です（英語の Name / Code / Price も可）。NotionからZIPで出た場合は展開してCSVを選んでください。反映前に、選んだ価格表と各金額を確認してください。

CSV行価格表の商品名・型番価格対応する登録商品照合結果

反映後は「商品表を共有保存」を押してください。生成・投稿時にも最新価格を照合し、変更があれば価格を更新して投稿文に反映します。すでにDiscordへ投稿した文章は自動更新されません。

CSV列：id,ja,en,code,domesticNames,price,sourceUrl,checkedAt,notionRowId。idとcheckedAtは空欄で構いません。価格の確認日時はブラウザの確認ボタンで記録します。

商品画像：画像ファイルを選ぶか、対応する画像URLを取り込みます。縦横比を保って自動調整します。画像が表示されたら「商品表を共有保存」で確定します。別のPCでも同じ画像を使えます。

WORKSPACE SETTINGS

割引の設定

S・A／AM／Bごとの基本割引額を自由に設定できます。共有保存すると、すべてのPCの新しい商品に反映されます。例外の商品は投稿作成画面で個別に変更できます。

販売投稿用Webhookの設定

初回だけ登録します。買取価格通知用とは別のWebhookを、Discordの販売チャンネルで作成してください。

  1. Discordで販売チャンネルの「チャンネルの編集」→「連携サービス」→「ウェブフック」を開きます。
  2. 専用Webhookを作成し、URLをコピーして下に貼り付けます。
  3. 保存後、「投稿を作る」でプレビューを確認します。設定の保存だけでは投稿しません。

利用者の事前登録

管理者だけが編集できます。自分自身の権限は変更できません。
